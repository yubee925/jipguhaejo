# 지도 색칠

코드: `lib/scale.ts` (`ORDERED`, `rankClasses`), `app/components/MapCard.tsx`, `app/components/DongMap.tsx`

## 무엇을 칠하나

각 동의 **실질 월 주거비**. 기준 매물은 그 동에서 현재 선택한 계약유형(전세/월세)의 중앙값 보증금·월세이고, 사용자 조건으로 매칭된 정책을 반영한다(`lib/evaluate.ts`의 `costByDong`).

## 색

7단계 순서형 다색 팔레트, 저렴 → 비쌈:

`#f9e03f`(노랑) → `#5bd97f`(초록) → `#24aeb5`(청록) → `#0d7dd4`(파랑) → `#6c3cab`(보라) → `#72034a`(자주) → `#421201`(암갈색)

- 색상은 다양하지만 밝기가 한 방향으로 어두워져 순서가 읽힌다.
- dataviz 검증기 기준: 이웃 색 CVD ΔE ≥ 9.3, 일반 시야 ΔE ≥ 15.8, 밝기 단조 감소(통과).
- 폴리곤 투명도 0.55, 흰색 1px 테두리. 호버 시 진회색, 선택 동은 검정 2px.

## 순위 기준으로 나누는 이유

- 금액 간격대로 나누면 한 동이 유난히 비쌀 때 나머지가 같은 색으로 몰린다.
- 그래서 **순위**로 나눈다. 금액이 같아도 동마다 다른 색(가나다순으로 앞선 동이 밝은 쪽).
- 대가: 색 차이가 금액 차이의 크기를 뜻하지 않는다. 정확한 금액은 지도 라벨과 순위 목록에서 본다.

## 변경 이력

파랑 단색 → 파랑·빨강 양방향 → 5단계 viridis → 7단계(광진구 7개 동) → 동점 구분. 자세한 이유는 [../decisions.md](../decisions.md).
