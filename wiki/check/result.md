- 새 원문(복지로 공지)은 이전 raw/P01 과 **같은 URL, 같은 본문**임 (공백 문자 NBSP↔일반 공백 차이만 있음). 그래서 8개 컬럼 추출값이 이전과 똑같고, 일치 수도 23/24 그대로.

## 같이 확인된 점 (불일치 아님)

- **P01 deposit_max·rent_max = NONE 일치**: 원문에도 상한이 없고, 정답지 note 에도 "보증금·월세 상한은 2024.4 폐지"라고 적혀 있어 서로 맞음.
- **P01 정답지 출처가 2차 자료**: source_url 이 토스뱅크 기사이고 verify_needed=Y. raw/P01 은 복지로(공식) 공지지만 신청 안내문이라 재산 기준이 없음. 재산 기준을 확인할 국토부 공고(지침) 또는 마이홈포털 상세를 raw/ 에 추가하는 게 좋음.
- **P01 신청기간 vs 정답지 apply_open (비교 컬럼 아님, 확인 필요)**: 공지 원문 18행 "2026년 3월 30일(월) 09시 ~ 2026년 5월 29일(금) 16시". 정답지는 apply_open=Y, note 에 "2026년부터 상시 신청". 검증일(2026-10-04) 기준으로는 공지상 신청기간이 끝난 상태라 서로 맞지 않음. 이후 상시/추가 접수 공지가 있는지 확인 전까지 정답지 수정은 보류.
- **P02 income_min**: 원문 "48% 초과"와 정답지 income_min=48 이 맞음 (비교 대상 컬럼은 아니지만 확인함).
- **예외 조건은 두 쪽 다 반영 안 함**: P02 제대군인 연령 최대 42세, P02 월세 60 초과 시 환산 합계 90만원(4.5%), P03 환산 합계 96만원(4.75%). 정답지와 AI 추출 모두 기본 상한(39세, 월세 60)만 넣음. 매칭 로직에서 이 예외를 쓸지는 따로 정해야 함.
