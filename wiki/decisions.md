# 결정 기록

최신 결정이 위. 각 항목: 무엇을 정했는지, 왜, 대안.

## 2026-09-29 지도는 OpenStreetMap 유지 (카카오맵 보류)

- 카카오맵 SDK로 전환을 시도했으나 카카오 디벨로퍼스 앱 등록(JavaScript 키, Web 도메인, 카카오맵 활성화)이 필요해 보류하고 커밋 전에 되돌렸다.
- OSM 공개 타일은 시연·소규모 트래픽에는 문제없으나, 트래픽이 커지면 이용 정책상 키가 있는 타일 제공자로 바꿔야 한다.
- 카카오맵은 Leaflet에 타일만 바꿔 끼울 수 없고(약관), 공식 SDK로 지도 컴포넌트를 다시 써야 한다.

## 2026-09-29 같은 금액의 동도 다른 색

- 순위 색을 "값" 기준에서 "동" 기준으로 바꿨다. 금액이 같으면 가나다순으로 앞선 동이 한 칸 밝다.
- 이유: 샘플 월세 기준 군자동·자양동이 같은 금액(81.7만원)이라 같은 색이 되어 구분이 안 됐다.
- 대가: 색 차이가 금액 차이를 뜻하지 않을 수 있다. 정확한 금액은 라벨·순위 목록으로 본다. → [concepts/map-coloring.md](concepts/map-coloring.md)

## 2026-09-29 대상 지역을 강남구 → 광진구

- 팀 결정. 법정동 7개 전부 사용(강남구 때는 5개 동).
- 자치구 이름은 `lib/region.ts`의 `DISTRICT` 한 곳에서 관리한다.

## 2026-09-29 AI 해설은 서버 재계산 + 제한형 응답 모드

- `/api/explain`은 화면이 보낸 계산 결과를 믿지 않고 조건만 받아 서버에서 다시 계산한 수치를 Claude에 보낸다.
- API 키가 없거나 호출이 실패하면 같은 수치로 만든 템플릿 답변을 돌려준다(제한형 응답 모드). → [tech/ai-agent.md](tech/ai-agent.md)
