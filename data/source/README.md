# raw — 원본 자료

LLM Wiki의 **원본 자료** 보관 폴더입니다. 여기 있는 파일은 사실의 출처이며, LLM은 읽기만 하고 수정하지 않습니다.

## 넣을 것

- 정책 공고문 (서울시 청년월세지원, 임차보증금 이자지원 등 PDF·HTML 저장본)
- 공공데이터 명세 (국토교통부 전월세 실거래가 API 문서 등)
- 법정동 경계·코드 자료 출처 문서
- 강사·팀 회의 메모, 피드백

## 규칙

- 파일 이름: `YYYY-MM-DD-짧은-설명.확장자` (예: `2026-10-02-서울시-청년월세지원-공고.pdf`)
- 원본은 고치지 않습니다. 내용이 바뀌면 새 날짜로 새 파일을 추가합니다.
- 파일을 넣은 뒤 LLM에게 "raw/파일명 을 위키에 반영해줘"라고 요청하면 `wiki/`가 갱신됩니다.
- 개인정보·API 키가 들어간 자료는 넣지 않습니다.
